# ФОРМАТ — сайт строительной компании

Одностраничный сайт строительной компании для портфолио и резюме.

## Стек

- HTML5
- CSS3 (адаптивная вёрстка, CSS-переменные, анимации)
- Vanilla JavaScript
- Google Fonts: Manrope и DM Mono

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта:

```bash
npx serve .
```

## Визуальная система

- Графит: `#20252B`
- Бетон: `#F2F1ED`
- Оранжевый: `#F28C28`
- Белый: `#FFFFFF`
