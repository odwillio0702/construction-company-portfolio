# FORMAT — construction company website

A responsive bilingual portfolio website for a construction company. English is the default language for an international audience; visitors can switch to Russian with the `EN / RU` control in the header.

## Features

- English / Russian language switcher
- Language preference saved in `localStorage`
- Responsive layout for desktop and mobile
- Project portfolio, services and contact sections
- Industrial visual system using Graphite `#20252B`, Concrete `#F2F1ED`, Orange `#F28C28` and White `#FFFFFF`

## Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Manrope and DM Mono

## Run locally

Open `index.html` in a browser or run a static server from the project root:

```bash
npx serve .
```
