03 / Website components

What is included
in the development

  • Responsive HTML structure for desktop, tablet and mobile screens.
  • Premium visual system with graphite backgrounds, concrete surfaces and orange accents.
  • Large Manrope typography and technical DM Mono labels.
  • Sticky navigation with smooth anchor links between sections.
  • English and Russian language switching with the visitor’s preference saved.
  • Mobile navigation with an accessible open and close control.
  • Scroll reveal animations for project and service cards.
  • Interactive hover effects for images, buttons and links.
  • Contact CTAs, email link and direct navigation to the contact section.
  • SEO description, semantic markup and descriptive image alt text.
Technical foundation

The project uses HTML5, CSS3 and Vanilla JavaScript. It is lightweight, easy to host and does not depend on a heavy framework.
